# TEAM SP DASE: Orbital Readiness Platform

Singapore Polytechnic student project. Not affiliated with or endorsed by NASA. Platform crew, readings and rules are fictional or simulated.

## Files
`index.html` (homepage) · `platform.html` (interactive platform) · `content.js` (ALL editable homepage content) · `styles.css` + `script.js` (homepage) · `space.js` (procedural planets) · `platform.css` + `platform.js` (platform) · `assets/` (images).
All paths are relative, so the site works under `https://<user>.github.io/TeamDASE/`.

## Run locally
Open `index.html`, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Publish on GitHub Pages
Copy every file and the `assets/` folder into the root of the `TeamDASE` repository (replace the old ones), commit and push. In the repository: Settings > Pages > deploy from the main branch, root folder. Wait about a minute, then hard-refresh.

## Edit content (only `content.js`)
- Team name, school line, headline, intro, disclaimer: `project`.
- Role colours: `roles.coder.color`, `roles.builder.color`, `roles.researcher.color` (hex). Cards, labels and filter buttons all follow.
- Team members: `team.members`. Set `name`, `roleKey` (`coder`, `builder` or `researcher`), `bio`, `contributions`, `photo`, `alt`. Currently 2 coders, 1 builder, 2 researchers.
- Photos: copy your file into `assets/` and change `photo` / `groupPhoto` (square crop 800x800 for members, 1600x900 for the group). A wrong path shows `assets/placeholder.svg`.
- Why we started, goals, learn cards (with sources), milestones: `why`, `goals`, `learn`, `progress`.
- Scientific data: add objects to `science.stats` with `label`, `value`, `unit`, `meaning`, `source`, `url`, `date`, `status` (`"sourced"` only after you checked the source). Numeric sourced `kPa` items appear in the chart.
- Astronaut names and profiles: top of `platform.js` (array `A`).

## Images and sources
No photographs or external images are used. The Earth, Moon and banded planet are generated by `space.js` in the browser, so they have no licence or credit requirements and are illustrations, not real imagery. To use real NASA or other photos, set `images.heroEarth` / `images.moon` in `content.js`, check the owner's usage guidelines, and list the credit in `imageCredits`.
Learn-card and science sources are linked in the page and listed under References.

## Not NASA data
No NASA endorsement, official statistic or live telemetry is claimed anywhere. Items marked Pending are placeholders.
